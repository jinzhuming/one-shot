## 同步修复

- 录屏按钮曾在准备、暂停切换期间被禁用后未完整恢复；现在录制、暂停两种稳定状态均可停止保存。
- 马赛克缓存曾仅用 `CGImage` 的内存标识作键，原图释放后可能发生标识复用，从而误命中其他图片。缓存条目现在保留原图，并继续限制为 6 项；回归测试验证原图在缓存有效时保留、缓存释放后销毁。保留原图会增加缓存占用，条目上限保持不变。
- 各浮层不再一次性隐藏系统材质；减少透明度和增强对比度可直接更新已存在的组件。
- 多个颜色控件共存时，颜色面板跟踪实际激活的控件，关闭编辑器时仍正确清理。
